# Developer Harness

Ein Python-Harness, das Markdown-Dateien als Spezifikation und SQLite als zentrale Aufgaben- und Zustandsdatenbank verwendet.

## Status

Die aktuelle Version enthält zunächst die Grundstruktur. Die Implementierung der einzelnen Komponenten folgt schrittweise.

## Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m harness --help
```
